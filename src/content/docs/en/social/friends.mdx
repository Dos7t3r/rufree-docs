## Finding people

Search by username. Everyone's profile lives at `/people/<username>`.

<Aside type="note">
Only people who have "discoverable" switched on appear in search. It is on by
default — turn it off to stay hidden. See [Visibility settings](/en/privacy/visibility/).
</Aside>

## What friends can see

Two layers decide this together:

1. **Each event's visibility** — only events marked "Friends" show details to friends
2. **Account-level switches** — whether course details, location and live status show at all

They combine as AND: an event marked "Friends" still shows only as busy if you have
turned course details off.

## Shared free time

Once you are friends you can see the free time you have in common. This uses only
the busy/free layer, so **it still works when every event is set to "Busy" with no
details.**
