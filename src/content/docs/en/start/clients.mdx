Every client shares one account. A change you make on one shows up on the others.

## Downloadable apps

| Platform | Installer | Requirement |
| --- | --- | --- |
| Windows | `.exe` | Windows 10 / 11, 64-bit |
| macOS | `.dmg` | macOS 14 or later |
| Android | `.apk` | Android 8.0 or later |

The download page highlights the build for the device you are on. Versions are read
from the public GitHub releases, where you can also find past versions.

## iPhone and iPad

The iOS app is not on the App Store yet. For now, open the web app in Safari and
choose **Share › Add to Home Screen**; it then behaves like a standalone app.
