订阅课程通知后，RUFREE 会检查新通知里有没有考试时间或考场信息。
匹配上的话，它会更新你日历里对应的那场考试。

<Aside type="caution">
这是**辅助**手段，不能替代学校的官方考试安排。时间和考场请以学校公布的为准。
</Aside>

## 需要什么条件

要让自动更新生效，需要同时具备：

1. 这门课的 syllabus 里已经有一场考试（见[上传 syllabus](/assistant/syllabus/)）
2. 这门课已经订阅了课程通知

通知里的时间会和 syllabus 里的考试做匹配，对上了才更新。

## 处理结果的含义

每次检查后，RUFREE 会列出它对每条通知做了什么。各种结果的意思：

| 结果 | 含义 |
| --- | --- |
| 时间已公布，已更新 | 找到了之前没有的考试时间，已写入 |
| 时间有变化，已更新并通知你 | 和原有时间不同，已更新并给你发通知 |
| 考场 / 时长已更新 | 时间没变，补充或更正了考场、时长 |
| 和现有时间一致 | 通知里的时间和你已有的一样，无需改动 |
| 你撤销过这条，未再使用 | 你之前撤销过这条结果，不会再自动应用 |
| 比已用的通知旧，已忽略 | 有更新的通知已经生效了 |

### 被跳过的情况

| 结果 | 含义 |
| --- | --- |
| 是其他 section 的时间 | 通知里说的是别的班 |
| 没对上 syllabus 里的考试 | 找不到对应的考试条目 |
| AI 不确定 | 置信度不够，不冒险写入 |
| 引用在原文里核对不到 | 无法在原文中验证，不采用 |
| 没有具体时间 | 通知只提了考试，没给时间 |
| 日期不在本学期 | 超出学期范围 |
| 结束时间不合理 | 时长明显不对 |
| 看不出是哪个班 | 无法判断 section |

## 撤销某条更新

每条自动应用的结果都可以撤销。撤销后，该考试恢复为之前的时间，
并且**这条通知不会再被重复应用**。

## 考试座位的姓氏

有些课按姓氏分配考场。你可以填一个姓氏，RUFREE 在读到这类通知时
会用它判断哪个考场是你的。这个字段最长 60 个字符，不填也不影响其他功能。
