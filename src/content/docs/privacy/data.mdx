## 保存了什么

| 类别 | 内容 |
| --- | --- |
| 账号 | 用户名、显示名、头像、校区、时区、语言 |
| 课表 | 导入的课表版本、手动添加的事件 |
| 课程通知 | 订阅配置和读取到的通知内容 |
| 资料 | 上传的 syllabus 和课程资料，以及提取出的文字 |
| 社交 | 好友关系、群组成员关系 |
| 订阅链接 | 日历订阅链接的名称、范围和过期时间 |

## 怎么删

| 想删掉 | 怎么做 |
| --- | --- |
| 一个手动事件 | 在日历里直接删 |
| 一个课表版本 | 在版本列表里删 |
| 一门课的通知订阅 | 在这门课下面移除订阅 |
| 一份 syllabus 或资料 | 在资料库里删 |
| 一个日历订阅链接 | 作废它 |
| 退出一个群组 | 在群组里退出 |

<Aside type="caution">
移除课程通知订阅时，由它更新过的考试时间会恢复成 syllabus 或 ACORN 的时间，
而不是留在原地。
</Aside>

## 日历订阅链接

RUFREE **不保存链接原文**，只保存它的指纹。这意味着：

- 链接丢了无法找回，只能作废重建
- 但也意味着数据库被看到也拿不到你的链接

## 注销账号

需要删除整个账号时，通过[反馈渠道](https://github.com/Dos7t3r/RUFREE-UPDATEs)联系。

<Aside type="caution">
提交反馈时**不要附上**验证码、日历订阅链接、Quercus feed 链接或完整课表截图。
</Aside>

## 反馈问题

更新日志和问题反馈都在公开的
[RUFREE-UPDATEs](https://github.com/Dos7t3r/RUFREE-UPDATEs) 仓库。
