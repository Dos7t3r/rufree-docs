## 两层设置

RUFREE 的可见性由两层共同决定：

```
第一层：每个事件的可见性（私密 / 忙碌 / 好友 / 群组）
            ↓ 与
第二层：账号级开关（是否显示课程详情、地点、实时状态……）
            ↓
        别人实际看到的内容
```

两层是「与」的关系——**任何一层拦住了，对方就看不到。**

## 第一层：事件可见性

| 可见性 | 效果 |
| --- | --- |
| 私密 | 完全隐藏，这段时间也不显示为忙碌 |
| 忙碌 | 只显示「忙碌」，不含任何详情 |
| 好友 | 好友可见详情 |
| 群组 | 群组成员可见详情 |

新事件套用账号的**默认可见性**。改默认值**不会**追溯修改已有事件。

## 第二层：账号级开关

| 开关 | 控制什么 |
| --- | --- |
| 显示课程详情 | 关掉后，即使事件设为「好友」，别人也只看到忙碌 |
| 显示地点 | 是否公开教室 / 地点 |
| 显示实时状态 | 是否让别人看到你「正在上课」 |
| 允许被搜索到 | 关掉后别人搜不到你 |
| 向非好友显示课程 | 不是好友的人能否看到你的选课 |

## 几个常见场景

**想共享空闲但不想让人知道我上什么课**
→ 事件设为「忙碌」，或者关掉「显示课程详情」。共同空闲照常可用。

**只想给小组作业的人看，不想给所有好友看**
→ 相关事件设为「群组」，别设「好友」。

**完全不想被人找到**
→ 关掉「允许被搜索到」。

**某几节课比较私人**
→ 单独把那几个事件设为「私密」，其余不变。

<Aside type="caution">
开始共享前，建议用自己的另一个视角确认一遍实际效果，而不是只看设置页。
</Aside>

## 共同空闲是个例外

共同空闲只用「忙 / 不忙」，不读详情。
所以把所有事件设成「忙碌」，完全不影响这个功能。

唯一的例外是「私密」——私密事件**不会**被算作忙碌，
别人可能把这段时间当成你有空。
