## 找到同学

搜索框里**至少输入 2 个字符**才会开始搜索。每个人的主页地址是 `/people/<用户名>`。

<Aside type="note">
只有把「允许被搜索到」打开的人才会出现在搜索结果里。这个开关默认开启，
想隐身就关掉它，见[可见性设置](/privacy/visibility/)。
</Aside>

## 添加好友

<Steps>

1. **用邮箱或用户名发起申请。**

   两种都可以。用户名前面带不带 `@` 都行，系统会自动去掉。

2. **等对方同意。**

   好友关系**需要双方确认**。对方会收到一条好友申请通知，
   在他接受之前，你们不是好友，也看不到彼此的日程。

3. **对方接受或拒绝。**

</Steps>

## 好友能看到什么

好友能看到的内容，由两层设置共同决定：

1. **每个事件的可见性** —— 只有标为「好友」的事件，好友才能看到详情
2. **账号级的几个开关** —— 是否显示课程详情、地点、实时状态

两层是「与」的关系：事件标了「好友」，但你关掉了「显示课程详情」，
好友看到的仍然只是忙碌。

## 共同空闲

加了好友之后，可以查看你们的共同空闲时间。这个功能只用「忙 / 不忙」这一层信息，
**即使对方把所有事件都设成「忙碌」而不显示详情，共同空闲依然能算出来。**

唯一的例外是「私密」事件——它不计入忙碌，那段时间别人会当你有空。

## 好友管理

每个好友都可以单独设置这些，**只对你自己生效，对方看不到**：

| 功能 | 说明 |
| --- | --- |
| 备注 | 给这个人起个只有你看得到的名字 |
| 置顶 | 把常找的人固定在列表前面 |
| 生日 | 记下对方生日，可以开启提醒 |
| 关注课表 | 对方课表变动时通知你 |

<Aside type="caution">
备注和生日是你自己记的信息，不会同步给对方，也不会改变对方的资料。
</Aside>

## 拉黑和删除

- **拉黑**：切断往来，之后可以解除
- **删除好友**：解除好友关系

两者都会让对方不再能看到你标为「好友」可见的日程。
