所有客户端共用一个账号。你在哪个端改了课表，其他端都会同步。

## 可下载的客户端

| 平台 | 安装包 | 系统要求 |
| --- | --- | --- |
| Windows | `.exe` | Windows 10 / 11（64 位） |
| macOS | `.dmg` | macOS 14 及以上 |
| Android | `.apk` | Android 8.0 及以上 |

下载页会自动标出适合你当前设备的版本。版本信息读取自公开的 GitHub 发布库，
历史版本也能在那里找到。

## iPhone 和 iPad

iOS App 还没有上架 App Store。现在的用法是打开网页版，
在 Safari 里点「分享 › 添加到主屏幕」，之后它会像一个独立 App 一样运行。
