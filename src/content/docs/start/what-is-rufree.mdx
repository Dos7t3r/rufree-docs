RUFREE 把你的课表变成一个可以和同学共享的东西：导入课表之后，你可以找出和朋友的共同空闲、
订阅课程通知、让 Assistant 从 syllabus 里整理出考试和作业草稿。

<Aside type="caution" title="不是官方服务">
RUFREE 是独立项目，不代表多伦多大学。课表、通知和考试信息都以学校官方渠道为准；
RUFREE 读取到的内容可能滞后或解析有误，重要日期请自行核对。
</Aside>

## 适合谁

目前以多伦多大学的课表场景为重点，支持三个校区：

- St. George（`uoft-st-george`）
- Mississauga / UTM（`uoft-utm`）
- Scarborough / UTSC（`uoft-utsc`）

校区在个人资料里设置，它决定你能看到哪些学期。

## 功能之间的依赖

有几个功能是有前后顺序的，跳过前一步会用不了后一步：

```
导入课表（.ics）
   ├── 共同空闲 / 群组共享
   ├── 日历订阅链接（导出回你自己的日历 App）
   ├── 订阅课程通知 ── 需要这门课在你当前生效的课表里
   └── 上传 syllabus ── 需要该学期有生效的课表
          └── Assistant 草稿 ── 你审核后才写入日历
                 └── 考试时间自动更新 ── 需要同时有 syllabus 考试和课程通知订阅
```

简单说：**先导入课表**，其余功能才有意义。

## 时区

账号有自己的时区设置，默认 `America/Toronto`。日历里所有时间按这个时区显示。
如果你在别的时区打开 RUFREE，看到的时间仍然是按账号时区渲染的——导入课表后建议先核对一下。
