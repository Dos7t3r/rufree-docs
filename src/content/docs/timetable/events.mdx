## 五种分类

日历里的每个事件都属于下面五类之一：

| 分类 | 说明 | 通常来自 |
| --- | --- | --- |
| 课程 | 正常上课 | 导入的课表 |
| 考试 | 考试 | syllabus 草稿、课程通知 |
| 作业 | 作业 | syllabus 草稿 |
| 截止日期 | Due date | syllabus 草稿 |
| 事件 | 个人安排 | 你手动添加 |

没有显式分类时，RUFREE 会按来源推断：手动添加的归为「事件」，课表导入的归为「课程」。

## 每个事件的可见性

**可见性是逐事件设置的**，共四档：

| 可见性 | 别人看到的内容 |
| --- | --- |
| 私密（private） | 什么都看不到，这段时间不显示为忙碌 |
| 忙碌（busy） | 只显示「忙碌」，不显示课程名、地点等任何详情 |
| 好友（friends） | 好友可以看到详情 |
| 群组（groups） | 所在群组的成员可以看到详情 |

新建事件时会套用你账号的**默认可见性**，之后可以单独调整某个事件。
默认值在设置里改，见[可见性设置](/privacy/visibility/)。

<Aside type="caution">
改默认值不会追溯修改已有事件。想让已有课表整体变私密，需要在课表那边调整，
而不是只改默认值。
</Aside>

## 编辑和删除

**只有手动添加的事件可以编辑或删除。** 由课表导入的课程不能单条修改——
它们属于某个课表版本，要改就重新导入或切换版本。
